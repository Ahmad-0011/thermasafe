# ThermaSafe — نظام مراقبة التعرّض الحراري

تطبيق ويب (عربي) لقياس جرعة التعرّض الحراري (Heat Exposure Dose) للعمال، مع واجهة للعامل وأخرى لمختص السلامة، قاعدة بيانات **Supabase** ومزامنة لحظية، جاهز للنشر على **Vercel**.

الملفات:
```
thermasafe-web/
├── index.html     ← التطبيق كامل (واجهة + منطق)
├── config.js      ← رابط ومفتاح Supabase (تعبّئه أنت)
├── schema.sql     ← سكربت إنشاء قاعدة البيانات (تشغّله مرة واحدة)
└── README.md      ← هذا الملف
```

> يعمل التطبيق فوراً بوضع **تجريبي محلي** حتى قبل ربط Supabase (بيانات وهمية في متصفحك). بعد الربط يتحوّل تلقائياً إلى قاعدة بيانات حقيقية مشتركة.

---

## الجزء 1 — إنشاء قاعدة البيانات على Supabase

1. أنشئ حساباً وسجّل الدخول على **https://supabase.com** ثم اضغط **New project**.
2. اختر اسماً وكلمة مرور لقاعدة البيانات، واختر أقرب Region، ثم **Create new project** (انتظر دقيقة حتى يجهز).
3. من القائمة الجانبية افتح **SQL Editor** → **New query**.
4. افتح ملف `schema.sql` من هذا المجلد، انسخ **كامل محتواه**، الصقه في المحرر، ثم اضغط **Run**.
   - سيُنشئ الجداول (`workers`, `accounts`, `sos_alerts`) + الدوال الآمنة + المزامنة اللحظية + بيانات تجريبية.
5. افتح **Project Settings** (أيقونة الترس) → **API**، وانسخ:
   - **Project URL**  (مثل `https://abcdxyz.supabase.co`)
   - **anon public** key (نص طويل يبدأ بـ `eyJ...`)
6. افتح ملف `config.js` وضع القيمتين مكان الفراغين:
   ```js
   window.SUPABASE_URL      = "https://abcdxyz.supabase.co";
   window.SUPABASE_ANON_KEY = "eyJhbGciOi...";
   ```
7. احفظ الملف. (لتجربته محلياً: شغّل خادماً بسيطاً — `npx serve` داخل هذا المجلد — لأن المتصفح يمنع بعض الطلبات من ملفات `file://`.)

---

## الجزء 2 — النشر على Vercel

### الطريقة أ — عبر واجهة Vercel (الأسهل، بدون أوامر)
1. ارفع مجلد `thermasafe-web` إلى مستودع على **GitHub** (New repository → ارفع الملفات).
2. سجّل الدخول على **https://vercel.com** بحساب GitHub.
3. **Add New… → Project** → اختر المستودع → **Import**.
4. الإعدادات: **Framework Preset = Other**، واترك بقية الحقول فارغة (لا يوجد build).
5. اضغط **Deploy** — خلال ثوانٍ ستحصل على رابط مثل `https://thermasafe.vercel.app`.

### الطريقة ب — عبر سطر الأوامر (Vercel CLI)
```bash
npm i -g vercel
cd thermasafe-web
vercel            # يفتح المتصفح لتسجيل الدخول أول مرة، ثم أسئلة سريعة
vercel --prod     # للنشر النهائي
```

> عند أي تعديل مستقبلي: ادفع التغيير إلى GitHub (الطريقة أ) أو أعد `vercel --prod` (الطريقة ب).

## ⚠️ ملاحظة أمان مهمة
لأغراض العرض/المشروع، كلمات المرور تُخزَّن كنص عادي في جدول `accounts` (لكنها **لا تُقرأ** من الواجهة إطلاقاً — الدخول يتم عبر دالة آمنة داخل قاعدة البيانات فقط). للاستخدام الإنتاجي الحقيقي يُنصح بالترقية إلى **Supabase Auth** وتجزئة كلمات المرور. أخبرني إن رغبت وأحوّله لك.
